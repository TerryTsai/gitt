# README screenshots

`repositories.png`, `files.png`, and `source.png` are Chromium captures of the
unmodified gitt interface, using fictional repositories, contributors, code,
and commit histories. They are illustrative examples, not benchmark fixtures.

The workspace contains 13 repositories. The `platform/atlas` example has 255
commits, 25 branches, 12 tags, and a nested query-engine source tree.

Captured on 2026-11-13 with JavaScript disabled and a 2× pixel density. List
viewports are 720 pixels wide; the source viewport is 760 pixels wide. Heights
fit the content with 14 pixels below it. No application styles or page content
were changed for the captures.
