gitt reads ordinary bare repositories and working checkouts in one directory. It creates empty repositories. Git transport and all other changes belong to your existing Git and SSH tools.

Browsing

Files shows committed content on the selected revision. Branch, tag, and commit links reload the same page with a different revision, preserving its path and other parameters. The selected name remains plain text beside the tabs throughout navigation. Staged, unstaged, and untracked files are excluded. Use the header breadcrumbs to move through directories. The fixed Search button opens repository-name search or committed file-path search within a selected repository. The matching Create button on home offers a Bare toggle that is checked by default.

File-list age, message, and author describe the last commit affecting that path, including descendants of a directory. Size and mode describe the selected file. File-list history lookup stops after 75 ms of cooperative work or 512 commits; missing history and limits leave unavailable fields as dashes with a notice.

Boundaries

Source previews are limited to 1 MiB and 20,000 lines. Highlighting is limited to 256 KiB, with plain text fallback. Committed raw downloads are limited to 8 MiB. Pages are limited to 2 MiB of HTML. Markdown is limited to 40,000 parse events and 128 levels of nesting. Larger content remains accessible with local Git or SSH.

Discovery stops at repository boundaries, skips symlink directories, and scans at most 10,000 directories and 1,000 repositories. History pages contain 50 commits; listings contain 200 entries per page. New repository views start on the HEAD branch. File links, previews, raw downloads, and search retain the selected branch, tag, or commit.

Supported storage

Self-contained SHA-1 repositories with loose or packed objects and refs. Linked worktrees, separate Git directories, external object stores, SHA-256, and reftable are unsupported. The Git index is not read. Submodule entries and LFS pointer files can be inspected; their contents are not fetched.

Access

There are no application accounts. Anyone who can reach this server can read and create repositories. Expose it only to your intended users. Committed files and their history remain visible regardless of current ignore rules.
